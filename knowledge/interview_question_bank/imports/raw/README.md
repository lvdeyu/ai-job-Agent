# 原始资料区

这里放尚未结构化的面试资料，例如：

- `.docx` 面试题文档
- `.pdf` 面经或课程讲义
- `.md` / `.txt` 笔记
- 从网页或聊天中复制的原始文本

这些文件只是 RAG 题库的素材来源，不会被系统直接导入 `question_bank_items`。

## 使用规则

- 原始资料可以格式不统一，也不需要包含 `id`、`skill_tags`、`scoring_rubric` 等字段。
- 不要把真实隐私信息、账号、密钥、公司内部资料放进这里。
- 如果资料来自第三方网站、课程或书籍，后续进入正式题库前需要做总结、改写和来源标记。
- 大文件可以先保存在本地资料目录，项目内只保留处理后的中间稿或来源说明。
